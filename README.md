Структура проекта:
- `src/db/__main__.py` — точка входа в приложение.
- `src/db/tui.py` — консольный интерфейс пользователя.
- `src/db/backend/memory.py` — логика хранения данных, таблиц и CRUD-операций.
- `src/db/__init__.py`, `src/db/backend/__init__.py` — файлы пакетов.

Реализованная функциональность:
- создание нескольких таблиц;
- выбор активной таблицы;
- добавление записей;
- чтение записей;
- фильтрация по одному и нескольким полям;
- обновление записей;
- удаление записей;
- обработка ошибок и некорректного ввода.

Запуск проекта:
python -m src.db
