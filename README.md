 Структура проекта:
-src/db/__main__.py — точка входа в приложение.
-src/db/tui.py — консольный интерфейс в виде класса ConsoleApp.
-src/db/backend/database.py — абстрактный интерфейс базы данных.
-src/db/backend/memory.py — классы MemoryDatabase и Table, реализующие хранение данных и CRUD.
-src/db/backend/file.py — файловая реализация СУБД в формате JSON.
-src/db/backend/csv.py — файловая реализация СУБД в формате CSV.
-src/db/backend/table.py — реализация таблиц, CRUD-операций, сортировки и индексации.
-src/db/backend/errors.py — пользовательские исключения.
-tests/test_memory.py — автоматизированные тесты для in-memory реализации.
-tests/test_file_database.py — тесты JSON-реализации.
-tests/test_csv_database.py — тесты CSV-реализации.
-tests/test_indexes.py — тесты индексации.
-tests/__init__.py — файл пакета тестов.

Реализованная функциональность:
-создание нескольких таблиц;
-выбор активной таблицы;
-добавление записей;
-чтение записей;
-фильтрация по одному и нескольким полям;
-обновление записей;
-удаление записей;
-сортировка записей по выбранному полю по возрастанию или убыванию;
-индексация данных по одному или нескольким полям;
-поддержка составных индексов;
-автоматическое обновление индексов при добавлении, изменении и удалении записей;
-использование индексов для ускорения чтения данных;
-поддержка хранения данных:
-- в памяти;
-- в JSON;
-- в CSV;
-обработка ошибок и некорректного ввода;
-автоматизированные тесты на unittest.

Запуск проекта: python -m src.db
