# Задания для первой лабораторной работы по дисциплине "Программирование и основы алгоритмизации"

## Как выполнять задания

- Делаете форк данного репозитория
- Переключаетесь между ветками и выполняете задания из **README** файла
- В основном репозитории Ваших лабораторный работ, в ветке **task1**:
    - Добавляете ссылку на ваш форк в **README** файл
    - Делаете **merdge request**, добавляете меня в ревьюверы, ждете апрув
    - Делаете мердж в **main**
